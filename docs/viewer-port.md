## 2. Data adapter: the first and smallest change

`library.js:165` hardcodes `fetch("/books/quotes/data/quotes.json")` and `start(data.books)` on line 178.

Replace the fetch with the manifest passed into `createLibrary()`. The internal book shape is close to the manifest's already — `id`, `author`, `title`, `year`, `hue`, `spine_seed` — so an adapter function mapping `Book` to the internal shape (`authors[0].join`, `yearRead` to `year`, `spineSeed` to `spine_seed`) is enough to get the existing renderer drawing a StoryGraph library on day one of M2. Do that first, before any refactor: it proves the port end to end in an hour and gives every later change something to regress against.

## 3. Self-mounting DOM

`library.js` currently queries roughly 30 element IDs from `index.html`: `#scene`, `#reticle`, `#aim-label`, `#fade`, `#boot`, `#intro`, `#controls-hint`, `#pause`, `#pause-btn`, `#mute-btn`, `#joystick`, `#bg-music`, `#esc-hint`, `#fallback`, `#paper-view`, `#backdrop`, `#stage`, `#book`, `#page-flow`, `#head-left/right`, `#pageno-left/right`, `#caption-*`, `#book-nav`, `#prev-btn`, `#next-btn`, and more.

Refactor:

1. `src/ui/template.js` exports a single function returning that markup as a `DocumentFragment`, with `bw-` prefixed classes and **no IDs at all**.
2. `createLibrary(root, ...)` appends it to `root` and resolves every element by `querySelector` against `root`, into one `els` object passed to the subsystems.
3. Delete `#paper-view` and the paper/note subsystem entirely — that's the reading-table note from the personal site, not part of this product.
4. `destroy()` removes the fragment, cancels the RAF loop, disposes geometries/materials/textures/render targets, and detaches every listener. The customize step mounts and unmounts this repeatedly; a leak there is a crash after ten preset clicks.

Approach: thread an explicit `theme` argument as the first parameter of every texture and builder function. There are roughly 40 call sites, all mechanical. **Do not use a module-level `setTheme` singleton** — the customize step may want two libraries alive at once, and a singleton makes `destroy()`/remount subtly wrong.

`handle.setTheme(theme)` regenerates the canvas textures and assigns `material.map` / light colours in place. Only geometry-affecting tokens would need a rebuild, and v1 has none.

Watch the light budget: the scene already runs ~8 real lights, with comments in `stacks.js` noting that only every other pendant carries a `PointLight` for fragment cost. Presets change colours and intensities, never counts.

## 5. Shelving

`stacks.js:530` currently derives the room from the year list:

```js
const aisleCount = Math.ceil(years.length / 2);
const unitCount = aisleCount + 1;
```

Aisle `i` shows `years[2i]` on the left face and `years[2i+1]` on the right. That already scales, and Jakub's 10 years produce 5 aisles.

Changes for M2:

1. **Groups, not years.** Generalize the input from `years[]` to `groups[]` where a group is `{ key, label, books }`. `year-read` is the only v1 producer; `to-read`, `currently-reading` and `undated` are extra groups with special placement (see `manifest-schema.md` 2.4).
2. **Spill.** One shelf face is 3 rows (`STACKS.rowBottoms`) of `STACKS.unitLength` 4.6 m, roughly 4.4 m usable per row after side panels and padding. `books.js` `fillRow()` already returns overflow for the next row, but a face that overflows all three rows currently drops books on the floor, conceptually. Add: a group claiming more books than one face holds takes consecutive faces, with the plaque repeated and marked (`2019 (1/2)`). Measure real capacity empirically in M2 rather than trusting the arithmetic — filler interleaving and gaps cut it substantially.
3. **Sort** within a group by author then title (D16).
4. **Small libraries.** A 12-book import must not get a cathedral. Clamp `unitCount` to a minimum of 2 and shrink `bounds` accordingly; verify with `minimal.csv`.

## 6. The library card overlay

`overlay.js` is built for quotes: highlight, blurred illegible filler, `fitType()` autofit so nothing scrolls. Keep the two-page book shell, the open/close animation, and `fitType()`. Replace the content with the checkout card (D20):

- Left page: title, authors, format, a stamp box with one date stamp per `datesRead` entry (a reread renders two — this is the detail that makes the card feel like an artifact).
- Right page: rating as pencil marks if present, review text if present, otherwise the ruled card continues empty.
- Every book opens, including one with nothing but title and author (D21).

Keep the same-year sibling navigation (`#book-nav`, `siblingsForBook` in `library.js`) — it becomes same-group navigation.

## 7. CSS scoping

`library.css` is 989 lines with 6 bare `html`/`body`/`*` rules and unprefixed class names (`.book`, `.stage`, `.reticle`, `.fade`) that would collide instantly with a Next.js app.

- Wrap everything under `.bw-root`, prefix every class `bw-`.
- Convert the bare `html`/`body` rules to `.bw-root` rules (they set overflow, cursor, background, and the Georgia stack).
- Fonts are `Georgia, "Times New Roman", serif` at three sites — **system stack only, no webfont dependency**, so nothing to bundle.
- The package injects the stylesheet once on first `createLibrary()`, guarded by a module flag.

## 8. Verification

Reuse the rodney workflow documented in the source `CLAUDE.md`, with its gotchas — they cost real time to discover:

- `rodney clear-cache` then `rodney reload --hard` after editing **any** ES module; Chrome caches modules by URL and a `?cb=` on the top page does not bust it.
- `RODNEY_HOME=/unique/dir` per agent if anything runs concurrently, or sessions get hijacked mid-test.
- Headless rAF can run at ~7 fps with dt clamped to 0.05 s — poll `state().grabState`, never assume animation timings.
- `rodney screenshot -w/-h` scales the capture only, not the JS viewport. Real mobile testing needs CDP `Emulation.setDeviceMetricsOverride` (390x844, `mobile: true`).

M2 acceptance:

1. `/home/jh/Downloads/storygraph.csv` renders 10 year-labelled shelf faces plus the to-read, currently-reading, and undated placements.
2. All five presets render and `setTheme()` switches between them without a rebuild or a leak (mount/unmount 20 times, watch `renderer.info.memory`).
3. `stress-500.csv` spills across faces without dropping books.
4. `minimal.csv` produces a proportionate small room.
5. The library card opens for a book with full data and for one with title and author only, with no scrolling in either (`pageFlow.scrollHeight - clientHeight === 0`).
6. Touch mode works at 390x844 via CDP emulation.
7. WebGL-unavailable fallback still renders a useful message.
